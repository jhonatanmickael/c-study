# Exercise 13 - Three-Number Sort

This exercise consists of developing a procedure in C that receives three integer values and sorts them in ascending order using pass-by-reference.

## Problem Statement

Create a procedure that receives 3 integer values as parameters and returns them sorted in ascending order. The sorting must be reflected in the original variables passed to the procedure.

## Input and Output Examples

**Example 1:**
- Input: 10, 5, 8
- Output: 5, 8, 10

**Example 2:**
- Input: 1, 3, 2
- Output: 1, 2, 3

**Example 3:**
- Input: -5, 0, -10
- Output: -10, -5, 0

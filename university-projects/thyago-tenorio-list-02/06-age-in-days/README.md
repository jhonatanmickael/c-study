# Age in Days Converter

## Description
This program implements a function that converts a person's age from years, months, and days into a single value representing the total age in days.

* **Year conversion**: 365 days
* **Month conversion**: 30 days

---

## Input and Output Examples

| Input (Years, Months, Days) | Output (Total Days) |
| :--- | :--- |
| `1, 2, 3` | `428` |
| `20, 5, 15` | `7465` |
| `0, 11, 29` | `359` |
| `30, 0, 0` | `10950` |
| `45, 8, 12` | `16687` |

# Ideal Weight Calculator

## Description
This program implements a function that calculates the ideal weight of a person based on their height and biological sex, using specific medical formulas.

---

## Calculation Formulas

| Sex | Formula |
| :--- | :--- |
| **Male** | `(72.7 * height) - 58` |
| **Female** | `(62.1 * height) - 44.7` |

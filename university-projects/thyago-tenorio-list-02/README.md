# List 02 - Functions and Modularization

This directory contains the second set of exercises for the Introduction to Programming course.

## Exercises Summary
Each folder below contains the source code (qXX.c), the compiled executable (main), and a README.md explaining the logic and examples.

1. Question 01 - Sphere Volume (01-sphere-volume)
   * Topic: Function parameters, return values, and floating-point precision.
2. Question 02 - Student Grade Average (02-calculate-grades)
   * Topic: Logic selection using characters, weighted/harmonic calculations, and modularization.
3. Question 03 - Prime Number Checker (03-prime-checker)
   * Topic: Prime number verification, loops, and boolean logic.
4. Question 06 - Age in Days (06-age-in-days)
   * Topic: Age conversion logic using years, months, and days.
5. Question 07 - Perfect Number Checker (07-perfect-number)
   * Topic: Proper divisors, summation logic, and boolean returns.

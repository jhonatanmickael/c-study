# List 02 - Functions and Modularization

This directory contains the second set of exercises for the Introduction to Programming course, focused on developing modular code using functions in C.

## Exercises Summary
Each folder below contains the source code (qXX.c), the compiled executable (main), and a specific README with test cases.

1. Question 01 - Sphere Volume (01-sphere-volume)
   * Topic: Function parameters, return values, and floating-point precision.
2. Question 02 - Student Grade Average (02-calculate-grades)
   * Topic: Logic selection using characters, weighted/harmonic calculations, and function modularization.

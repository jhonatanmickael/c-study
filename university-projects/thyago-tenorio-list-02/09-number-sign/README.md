# Number Sign Checker

## Description
This program implements a function that classifies an integer as positive, negative, or neutral (zero). It demonstrates the use of integer-based status codes to handle multiple logical states in C.

---

## Input and Output Examples

| Input | Output Status Code | Console Message |
| :--- | :--- | :--- |
| `15` | `1` | `15 é positivo` |
| `-7` | `0` | `-7 é negativo` |
| `0` | `-1` | `0 é neutro` |

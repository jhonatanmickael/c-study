# Exercise 08 - Swimmer Categorization

This exercise consists of developing a procedure in C for the age classification of athletes, applying concepts of parameters by reference.

## Problem Statement

Create a procedure that receives a swimmer's age as a parameter and returns, also via parameter, the swimmer's category according to the table below:

| Age | Category |
| :--- | :--- |
| 5 to 7 years | Infantil A |
| 8 to 10 years | Infantil B |
| 11 to 13 years | Juvenil A |
| 14 to 17 years | Juvenil B |
| 18 years and older (inclusive) | Adulto |

## Input and Output Examples

**Example 1:**
- Input: 6
- Output: Sua categoria é Infantil A

**Example 2:**
- Input: 12
- Output: Sua categoria é Juvenil A

**Example 3:**
- Input: 25
- Output: Sua categoria é Adulto

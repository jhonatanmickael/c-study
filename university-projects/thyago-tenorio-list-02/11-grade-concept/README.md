# Student Grade Concept

## Description
This program implements a function that receives a student's final average and returns their corresponding concept grade based on a specific grading scale.

---

## Grading Scale

| Score Range | Concept |
| :--- | :--- |
| 0.0 to 4.9 | **D** |
| 5.0 to 6.9 | **C** |
| 7.0 to 8.9 | **B** |
| 9.0 to 10.0 | **A** |

# Even or Odd Checker

## Description
This program implements a function that receives an integer and verifies if it is even or odd. The function returns a boolean value, where `true` (1) represents an even number and `false` (0) represents an odd number.

---

## Input and Output Examples

| Input | Output (Boolean) | Description |
| :--- | :--- | :--- |
| `2` | `True (1)` | Even number |
| `7` | `False (0)` | Odd number |
| `0` | `True (1)` | Even number |
| `-4` | `True (1)` | Even number |

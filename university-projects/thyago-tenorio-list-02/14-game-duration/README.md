# Exercise 14 - Game Duration Calculator

This exercise consists of developing a procedure in C to calculate the total duration of a game based on its start and end times, applying concepts of pass-by-reference.

## Problem Statement

Create a procedure that receives the start time and end time of a game as parameters. Both start and end times are split into 2 separate integer values: hours and minutes. The procedure must return, also via parameters, the total duration of the game in hours and minutes. 

Consider that the maximum duration of a game is 24 hours and that the game can start on one day and finish on the next day.

## Input and Output Examples

**Example 1:**
- Input: 14 00 16 30
- Output: 2 30

**Example 2:**
- Input: 23 15 1 45
- Output: 2 30

**Example 3:**
- Input: 15 00 15 00
- Output: 24 00

# Exercise 19 - Highest and Lowest Value Finder

This exercise consists of developing a procedure in C that reads a fixed amount of 50 integer values and returns both the highest and lowest numbers found using pass-by-reference.

## Problem Statement

Create a procedure that reads 50 integer values from the input. The procedure must determine which of the entered numbers is the highest and which is the lowest, returning these two results via parameters (pointers) to the calling function.

## Input and Output Examples

**Example 1:**
- Input: 12 5 27 3 19 [followed by 45 more integers ending in 50]
- Output: 50 3

**Example 2:**
- Input: -5 -12 0 -1 8 [followed by 45 more integers ending in -20]
- Output: 8 -20

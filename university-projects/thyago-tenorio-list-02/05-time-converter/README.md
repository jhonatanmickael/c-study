# Time Conversion (Factory Duration)

## Problem Description
The goal of this exercise is to implement a function that converts a factory's operation time, provided in total seconds, into a formatted time duration of hours, minutes, and seconds.

The problem specifically requires that the results (hours, minutes, and seconds) be returned to the main program via **parameters** (using pointers/pass-by-reference), rather than through a single return value.

---

## Input Format
* An integer value representing the total duration in seconds.

## Output Format
* The calculated time split into three distinct integer values:
    * **Hours**
    * **Minutes**
    * **Seconds**

---

## Execution Examples

**Example 1:**
```text
Input:
3661
Output:
1h 1m 1s

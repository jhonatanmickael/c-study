# Sphere Volume Calculator

## Description
This program calculates the volume of a sphere based on a given radius. The calculation is performed by a dedicated function that applies the geometric formula:
- **Formula**: $V = \frac{4}{3} \cdot \pi \cdot R^3$
- **Pi ($\pi$)**: 3.14159

The program ensures precision by using floating-point types (`double`) and modularizes the math logic into a separate function.

---

## Input and Output Examples

| Type | Input Example | Output Example |
| :--- | :--- | :--- |
| **Small Sphere** | `3.0` | `113.10` |
| **Medium Sphere** | `5.0` | `523.60` |
| **Large Sphere** | `10.0` | `4188.79` |
| **Unit Sphere** | `1.0` | `4.19` |

# Triangle Classifier

## Description
This program verifies if three given lengths can form a triangle and, if so, identifies whether it is Equilateral, Isosceles, or Scalene.

---

## Classification Rules

| Type | Condition |
| :--- | :--- |
| **Equilateral** | All three sides are equal. |
| **Isosceles** | Exactly two sides are equal. |
| **Scalene** | All three sides are different. |

# Student Grade Average Calculator

## Description
This program calculates three different types of averages for a student's grades based on a provided character code. The calculation method is determined by the input character:
- **'A'**: Arithmetic Average.
- **'P'**: Weighted Average (Weights: 5, 3, 2).
- **'H'**: Harmonic Average.

The program uses a dedicated function to perform the calculations, ensuring modularity and clear output for academic purposes.

---

## Input and Output Examples

| Type | Input Example | Output Example |
| :--- | :--- | :--- |
| **Arithmetic** | `7.0 8.0 9.0 A` | `8.00` |
| **Weighted** | `10.0 5.0 2.0 P` | `6.90` |
| **Harmonic** | `1.0 2.0 4.0 H` | `1.71` |
| **Invalid** | `5.0 5.0 5.0 Z` | `0.00` |

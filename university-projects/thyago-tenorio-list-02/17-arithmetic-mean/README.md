# Arithmetic Mean of Indeterminate Values

## Description
This program implements a function that reads an indeterminate number of positive values and returns their arithmetic mean.

---

## Input and Output Examples

| Input | Output |
| :--- | :--- |
| `10`, `20`, `30`, `0` | `20.00` |
| `5`, `15`, `-1` | `10.00` |
| `2.5`, `7.5`, `0` | `5.00` |

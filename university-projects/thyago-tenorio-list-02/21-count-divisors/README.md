# Question 21 - Divisor Counter

## Description
This program implements a function that receives a positive integer as a parameter and returns the total number of divisors for that value.

---

## Input and Output Examples

If the input is `N = 6`, the output will be:

| Input | Logic (Divisors) | Output (Count) |
| :--- | :--- | :--- |
| `6` | `{1, 2, 3, 6}` | `4` |

If the input is `N = 10`, the output will be:

| Input | Logic (Divisors) | Output (Count) |
| :--- | :--- | :--- |
| `10` | `{1, 2, 5, 10}` | `4` |

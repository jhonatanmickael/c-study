# Perfect Number Checker

## Description
This program implements a function to verify if a given integer is a perfect number. A number is considered perfect when it is equal to the sum of its divisors, excluding the number itself.

---

## Input and Output Examples

| Input | Output (Boolean/Status) |
| :--- | :--- |
| `6` | `True (1 + 2 + 3 = 6)` |
| `28` | `True (1 + 2 + 4 + 7 + 14 = 28)` |
| `10` | `False (1 + 2 + 5 = 8)` |
| `496` | `True` |
| `12` | `False` |

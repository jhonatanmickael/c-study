# Factorial Calculator

## Description
This program implements a function that receives a positive integer and calculates its factorial.

---

## Input and Output Examples

| Input | Output |
| :--- | :--- |
| `5` | `120` |
| `4` | `24` |
| `0` | `1` |
| `1` | `1` |

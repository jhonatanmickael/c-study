# Prime Number Checker (Question 03)

This project contains an optimized C function to check if a positive integer is prime. This exercise is part of the Introduction to Programming course.

## Problem Description
Create a function that receives a positive integer as a parameter and returns a boolean value: **True (1)** if the value is prime and **False (0)** otherwise.

## Test Examples

| Input | Expected Output |
| :--- | :--- |
| `1` | Not prime |
| `2` | Prime |
| `4` | Not prime |
| `13` | Prime |
| `25` | Not prime |
| `97` | Prime |

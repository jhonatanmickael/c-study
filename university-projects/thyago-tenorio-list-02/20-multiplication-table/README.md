# Multiplication Table (1 to N)

## Description
This program implements a procedure that receives an integer parameter `N` and prints the multiplication table from 1 up to `N` in a specific format.

---

## Input and Output Examples

If the input is `N = 5`, the output will be:

| Format | Output |
| :--- | :--- |
| `1 x N = N` | `1 x 5 = 5` |
| `2 x N = 2N` | `2 x 5 = 10` |
| `...` | `...` |
| `N x N = N²` | `5 x 5 = 25` |

# Exercise 01 - Array Initialization and Sum

This exercise consists of developing a program in C to perform initial operations with a one-dimensional array (vector), focusing on direct indexing, specific memory position summation, value modification, and sequential output.

## Problem Statement

[cite_start]Create a program that possesses an integer array named A capable of storing 6 elements[cite: 3]. The program must execute the following sequential steps:
- [cite_start]Initialize the vector A with the values: 1, 0, 5, -2, -5, 7[cite: 5].
- [cite_start]Store the sum of the values located at positions A[0], A[1], and A[5] into a simple integer variable and print this sum on the screen[cite: 6].
- [cite_start]Modify the vector at position 4, assigning the value 100 to this specific index[cite: 7].
- [cite_start]Display each value of the updated vector A on the screen, printing one element per line[cite: 8].

## Input and Output Examples

**Example 1:**
- [cite_start]Input: None (values are statically assigned within the source code)[cite: 5].
- Output: 
  13
  1
  0
  5
  -2
  100
  7

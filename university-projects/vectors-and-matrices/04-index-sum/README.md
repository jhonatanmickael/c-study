# Exercise: Sum of Vector Positions

Write a program that reads a vector of 8 positions and then reads two values, X and Y, corresponding to any two positions in the vector. At the end, your program must print the sum of the values found at the respective positions X and Y.

## Input and Output Examples

### Example 1

**Input:**
```text
10
20
30
40
50
60
70
80
2
5

(Note: The first 8 values fill the vector from position 0 to 7. The values 2 and 5 correspond to X and Y).

**Output**
```text
90

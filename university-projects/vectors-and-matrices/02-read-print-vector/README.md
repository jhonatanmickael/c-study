# Exercise 02 - Read and Display Vector

This exercise consists of developing a program in C that reads a sequence of 10 integer values from the standard input, stores them inside a one-dimensional array (vector), and subsequently displays all the recorded values back to the screen.

## Problem Statement

Create a program that reads 6 integer values from the input. After receiving and storing all 6 numbers sequentially within an array, the program must traverse the structure to display each of the read values on the screen.

## Input and Output Examples

**Example 1:**
- Input: 10 20 30 40 50 60
- Output: 10 20 30 40 50 60

**Example 2:**
- Input: -1 5 0 12 -8 3
- Output: -1 5 0 12 -8 3

# List 03 - Vectors and Matrices

This directory contains the third set of exercises for the Introduction to Programming course, focusing on one-dimensional arrays (vectors) and multi-dimensional arrays (matrices).

## Exercises Summary
Each folder below contains the source code (qXX.c), the compiled executable (main), and a README.md explaining the logic and examples.

01. Question 01 - Array Initialization and Sum (01-array-sum)
    * Topic: Static array initialization, direct index positioning, and element modification.
02. Question 02 - Read and Display Vector (02-read-print-vector)
    * Topic: Sequential input loops and standard output array traversal.
03. Question 03 - Component Squaring (03-vector-square)
    * Topic: Real number tracking, multiple array handling, and mathematical power scaling.
04. Question 04 - Position Index Sum (04-index-sum)
    * Topic: Bound-checked index mapping and arithmetic evaluations.
05. Question 05 - Even Number Counter (05-count-evens)
    * Topic: Parity checking validation loops and iterative counters.
06. Question 06 - Reverse Order Vector (06-reverse-vector)
    * Topic: Inverted array indexing and countdown iteration constraints.
07. Question 07 - Menu-Driven Vector Options (07-vector-menu)
    * Topic: Execution flow control flags, bidirectional traversal, and error boundary handling.
08. Question 08 - Vector Subtraction (08-vector-subtraction)
    * Topic: Multi-vector transformations, parallel loop mapping, and vector-space subtraction.
09. Question 09 - Elements Greater Than Ten (09-matrix-count-ten)
    * Topic: Matrix parsing, 2D array coordinates, and nested loop counters.
10. Question 10 - Identity-Like Matrix Definition (10-matrix-identity)
    * Topic: Main diagonal row-column matching conditionals and multi-dimensional structures.
11. Question 11 - Index Product Matrix (11-matrix-product)
    * Topic: Grid coordinate arithmetic and structural nested loop population.
12. Question 12 - Highest Value Location (12-matrix-highest-location)
    * Topic: Global extreme value search trackers and coordinate tracking outputs.
13. Question 13 - Matrix Value Search (13-matrix-search)
    * Topic: Linear search grids, coordinate lookups, and multi-dimensional flag validation.

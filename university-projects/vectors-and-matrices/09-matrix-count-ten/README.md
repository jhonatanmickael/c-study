# Exercise 09 - Matrix Value Counting

This exercise consists of developing a program in C that reads a two-dimensional array (matrix) of $4 \times 4$ integers using dynamic memory allocation. The program must count and display how many elements stored in the matrix are strictly greater than 10.

## Problem Statement

Leia uma matriz $4 \times 4$, conte e escreva quantos valores maiores que 10 ela possui.

## Input and Output Examples

**Example 1:**
- Input:
  - Matrix (4x4): 
    1  15   3   8
    12  5   7  20
    9  14   2   6
    0   4  11  13
- Output:
  - Result: 6 values greater than 10

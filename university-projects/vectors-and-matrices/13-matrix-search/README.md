# Exercise 12 - Matrix Linear Search

This exercise consists of developing a program in C that dynamically allocates a two-dimensional array (matrix) of $5 \times 5$ integers. The program reads user inputs to populate the matrix, prompts for a target value $X$, and performs a linear search to determine and display all coordinate locations (row and column) where $X$ is positioned, or outputs a "not found" message if it does not exist.

## Problem Statement

Leia uma matriz $5 \times 5$. Leia também um valor $X$. O programa deverá fazer uma busca desse valor na matriz e, ao final, escrever a localização (linha e coluna) ou uma mensagem de “não encontrado”.

## Input and Output Examples

**Example 1:**
- Input:
  - Matrix (5x5): Filled with numbers 1 to 25 sequentially
  - Target Value X: 12
- Output:
  - Result: Localização encontrada: Linha 3 e coluna 2.

**Example 2:**
- Input:
  - Matrix (5x5): Filled with numbers 1 to 25 sequentially
  - Target Value X: 99
- Output:
  - Result: [!] O valor 99 não foi encontrado [!]

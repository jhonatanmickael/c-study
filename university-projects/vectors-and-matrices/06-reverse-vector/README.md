# Exercise 06 - Reverse Order Vector

This exercise consists of developing a program in C that reads a fixed-size sequence of 6 integers into a one-dimensional array and displays the elements on the screen in the exact reverse order of their insertion.

## Problem Statement

Crie um programa que lê 6 valores inteiros e, em seguida, mostre na tela os valores lidos na ordem inversa.

## Input and Output Examples

**Example 1:**
- Input: 10 20 30 40 50 60
- Output: 60 50 40 30 20 10

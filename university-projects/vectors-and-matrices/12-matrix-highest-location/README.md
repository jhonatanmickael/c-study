# Exercise 12 - Matrix Maximum Value and Location

This exercise consists of developing a program in C that dynamically allocates a two-dimensional array (matrix) of $4 \times 4$ integers. The program reads values to populate the matrix, displays the full matrix layout, and tracks both the maximum value contained within it and its precise coordinate locations (row and column identifiers).

## Problem Statement

Leia uma matriz $4 \times 4$, imprima a matriz e retorne a localização (linha e a coluna) do maior valor.

## Input and Output Examples

**Example 1:**
- Input:
  - Matrix (4x4):
    5   12  3   8
    9   42  1   7
    11  2   15  6
    0   14  22  10
- Output:
  - Generated Matrix displayed on screen.
  - Result: 
    -> Maior número: 42
       Localização: 2/2

# Exercise 07 - Vector Menu Operations

This exercise consists of developing a program in C that reads an array of 5 real numbers and an integer code. Based on the provided code, the program executes specific structural actions, such as printing the array elements in direct or reverse order, signaling errors, or terminating execution.

## Problem Statement

Faça um programa que leia um vetor de 5 posições para números reais e, depois, um código inteiro. Se o código for zero, finalize o programa; se for 1, mostre o vetor na ordem direta; se for 2, mostre o vetor na ordem inversa. Caso, o código for diferente de 1 e 2 escreva uma mensagem informando que o código é inválido.

## Input and Output Examples

**Example 1:**
- Input:
  - Vector elements: 1.5 2.3 4.0 5.5 7.2
  - Code: 1
- Output: 1.50 2.30 4.00 5.50 7.20

**Example 2:**
- Input:
  - Vector elements: 1.5 2.3 4.0 5.5 7.2
  - Code: 2
- Output: 7.20 5.50 4.00 2.30 1.50

**Example 3:**
- Input:
  - Vector elements: 1.5 2.3 4.0 5.5 7.2
  - Code: 5
- Output: Código inválido.

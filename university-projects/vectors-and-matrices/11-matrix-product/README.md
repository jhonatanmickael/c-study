# Exercise 11 - Matrix Multiplication Table Generation

This exercise consists of developing a program in C that dynamically allocates a two-dimensional array (matrix) of $4 \times 4$ integers. The program must automatically populate each position with the product of its row and column identifiers, subsequently displaying the generated matrix on the screen.

## Problem Statement

Faça um programa que preenche uma matriz $4 \times 4$ com o produto do valor da linha e da coluna de cada elemento. Em seguida, imprima na tela a matriz.

## Input and Output Examples

**Example 1:**
- Input:
  - None (The matrix values are computed automatically by the program)
- Output:
  - Generated Matrix:
    1	2	3	4	
    2	4	6	8	
    3	6	9	12	
    4	8	12	16

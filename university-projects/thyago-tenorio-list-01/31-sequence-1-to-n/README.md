# Question 31: Integer Sequence from 1 to N

## Statement
Write a program that reads an integer value N and prints all integer values between 1 (inclusive) and N (inclusive). Consider that N will always be greater than ZERO.

## Input Example
5

## Output Example
1 2 3 4 5

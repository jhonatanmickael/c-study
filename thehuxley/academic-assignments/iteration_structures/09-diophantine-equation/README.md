# Question 33: Linear Diophantine Equation

## Statement
Given the coefficients $A$, $B$, and $C$ of the equation $Ax + By = C$, determine if there exist integer solutions for $x$ and $y$.
A solution exists if and only if $C$ is a multiple of the Greatest Common Divisor (GCD) of $A$ and $B$.

## Difficulty
3/5

## Input Format
Three integers: $A$, $B$, and $C$.

## Output Format
A single line containing 'S' if a solution exists, or 'N' otherwise.

## Example
**Input:**
14 10 100

**Output:**
S
